## Troubleshooting:

**"Invalid credentials"**

- Make sure you created the user in Supabase first
- Check you clicked "Auto Confirm User"

**"Email not confirmed"**

- Go back to Supabase → Users
- Find your user, click the 3 dots, select "Confirm email"

**Can't access Supabase**

- Your project URL: `vvjjbjreauspzrweriof.supabase.co`
- Make sure you're logged into the right account
