# Supabase Setup Guide

Follow these steps to set up your Supabase project from scratch.

## 1. Create a Project

1.  Go to [supabase.com](https://supabase.com) and sign in.
2.  Click **"New Project"**.
3.  Choose your organization and enter a Name (e.g., `Amal Attendance`).
4.  Set a strong database password.
5.  Select a region close to you.
6.  Click **"Create new project"**.

## 2. Get Credentials

1.  Once the project is ready, go to **Project Settings** (cog icon) -> **API**.
2.  Copy the **Project URL** (`NEXT_PUBLIC_SUPABASE_URL`).
3.  Copy the **anon public** key (`NEXT_PUBLIC_SUPABASE_ANON_KEY`).
4.  Update your local `.env.local` file with these values.

## 3. Run Database Migration

1.  Go to the **SQL Editor** in the side menu.
2.  Click **"New Query"**.
3.  Paste the following SQL into the editor and click **"Run"**.

```sql
-- 1. Reset (Caution: Deletes existing data)
drop table if exists attendance_logs cascade;
drop table if exists employees cascade;

-- 2. Create Employees Table
create table employees (
  id bigint generated by default as identity primary key,
  staff_id text unique not null,
  name text not null,
  role text not null,
  department text not null,
  email text,
  status text default 'Active',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 3. Create Attendance Logs Table
create table attendance_logs (
  id bigint generated by default as identity primary key,
  employee_id bigint references employees(id) not null,
  employee_name text not null,
  check_in timestamp with time zone,
  check_out timestamp with time zone,
  date date not null default CURRENT_DATE,
  status text not null, -- 'On Time', 'Late'
  location text,
  duration text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 4. Create Leave Requests Table
create table leave_requests (
  id bigint generated by default as identity primary key,
  employee_id bigint references employees(id) not null,
  employee_name text not null,
  type text not null,
  start_date date not null,
  end_date date not null,
  reason text,
  status text default 'Pending',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 5. Enable RLS
alter table employees enable row level security;
alter table attendance_logs enable row level security;
alter table leave_requests enable row level security;

-- 6. Create Policies (Public Demo Mode)
create policy "Enable all access for all users" on employees for all using (true);
create policy "Enable all access for all users" on attendance_logs for all using (true);
create policy "Enable all access for all users" on leave_requests for all using (true);
```
